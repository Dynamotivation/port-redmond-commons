# Contributing

Contributions are welcome through issues and pull requests.

By submitting a contribution, you agree that it is licensed under the
repository's [MIT License](LICENSE). You represent that you have the right to
submit the contribution under those terms.

Do not add third-party code or assets without recording their source,
copyright, and complete redistribution terms in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Keep shared controls platform-neutral, preserve existing public contracts when
possible, and run the affected project builds before opening a pull request.
